# ROKN OS

واجهة عربية لإدارة الطلبات والمخزون والتصنيع والتوصيل.

## التشغيل
1. اربط المستودع بخدمة Netlify (لا يعمل الـ API على GitHub Pages).
2. عيّن متغيري البيئة `DATABASE_URL` (رابط اتصال Neon من لوحة Neon) و `ROKN_ADMIN_TOKEN` (رمز سري طويل خاص بك) في إعدادات Netlify، ولا تضفهما إلى GitHub.
3. انشر الموقع. عند الدخول أدخل رمز الإدارة نفسه في شاشة الاتصال.
4. قاعدة Neon هي المصدر الأساسي؛ Google Sheets للتقارير فقط. مزامنة Sheets الآلية غير مفعّلة بعد.

**مهم:** بيانات localStorage التجريبية القديمة لا تُرحّل تلقائيًا. راجع الطلبات قبل إدخالها حتى لا تُعاد الطلبات الملغية أو المكررة.
